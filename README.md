# 봉신연의 애장판 한국어 패치 v0.1.0 (베타)

PlayStation용 일본판 `Houshin Engi - Aizouban`(SLPM-86209)에 적용하는 비공식 한국어 차분 패치입니다. 이 배포물에는 원본 또는 패치된 전체 게임 이미지가 들어 있지 않습니다.

## 지원 원본

- 형식: 원본 CD를 `BIN/CUE`로 덤프한 단일 `MODE2/2352` 트랙
- BIN 크기: `363,266,400`바이트
- BIN SHA-256: `91DBAA601180A482DC00A42ED3CB6153367BCFB550C2058F86C4BCCC13D3E1C0`
- 게임 ID: `SLPM-86209`

ISO, CHD, PBP, 병합·트림된 이미지, 다른 덤프, 이미 패치된 이미지에는 적용하지 마세요. 이전 시험판 패치 위에 덧씌우지 말고 반드시 위 해시의 깨끗한 원본에서 시작해야 합니다.

## Windows에서 적용하기

동봉된 적용기는 64비트 Windows용이며 Windows PowerShell을 사용합니다. 다른 운영체제에서는 호환되는 xdelta3로 아래의 수동 적용 명령을 실행하세요.

1. ZIP을 새 폴더에 모두 풉니다.
2. 깨끗한 원본 BIN을 그 폴더에 복사하고 이름을 정확히 `Houshin Engi - Aizouban (Japan).bin`으로 맞춥니다.
3. 에뮬레이터를 완전히 종료한 뒤 `apply_patch.bat`를 실행합니다.
4. 성공 메시지와 출력 SHA-256을 확인합니다.
5. 동봉된 `Houshin Engi - Aizouban (Japan) [Korean v0.1.0].cue`를 에뮬레이터에서 불러옵니다.

스크립트는 원본과 결과물의 SHA-256을 모두 검사하며, 기존 결과 파일을 덮어쓰지 않습니다. CUE는 별도 데이터가 아니라 생성될 한국어 BIN의 파일명과 원본 트랙 구조를 알려 주는 작은 목차 파일입니다.

### 수동 적용

```bat
tools\xdelta3.exe -d -s "Houshin Engi - Aizouban (Japan).bin" "Houshin_Engi_Aizouban_Korean_v0.1.0.xdelta" "Houshin Engi - Aizouban (Japan) [Korean v0.1.0].bin"
```

정상 결과:

- 크기: `363,266,400`바이트
- SHA-256: `559517B52DA9E0DA5BF7C750331754B5C56379F5EDE8C12FBDB6C5B0527B0567`

동봉 파일의 무결성 값은 `SHA256SUMS.txt`에 있습니다. 사용하는 SHA-256 검사 도구로 각 파일의 값을 비교할 수 있으며, GitHub 릴리즈에는 ZIP과 단독 xdelta의 외부 체크섬 파일도 함께 제공합니다.

## 패치 범위 요약

- 본편 대사 4,297레코드(화면 줄 10,012줄)와 화자명
- 한국어 표시용 커스텀 문자 맵 1,048개와 이름 입력 글자표
- 캐릭터·기술·아이템·지명·스토리 제목·메뉴·전투/저장 UI·도움말·설명·HISTORY 등 고정 문구
- 새 게임 기본 이름 `태공망` 및 후리가나 제거
- PROLOGUE와 CHAPTER 1~4 영상 자막
- 전투/이벤트 지명, 전투 조건·목표·결과, 시작/타이틀 화면 등 이미지 글자
- UI 안전 범위의 띄어쓰기 30건과 겹침·잔여 일본어 보정

정확한 수량, 검증 범위 및 의도적으로 보류한 항목은 `PATCH_SCOPE.md`를 확인하세요.

## 주의 사항

- 이번 버전은 정적 구조·해시·섹터·복원 검증을 통과한 베타입니다. 엔딩까지의 전체 플레이 검증은 아직 완료되지 않았습니다.
- 화면 폭, 고정 슬롯 크기, 스크립트 용량 또는 메뉴 제어 코드 손상 위험이 있는 띄어쓰기 후보 40건은 의도적으로 보류했습니다.
- 정체가 확정되지 않은 그래픽 아이콘 2개는 원형을 유지했습니다. OPENING/ENDING을 포함한 모든 영상 속 글자를 100% 한글화했다고 보장하지 않습니다.
- 메모리 카드 세이브 데이터 자체는 변경하지 않았지만 모든 기존 세이브와의 호환성은 완주 검증되지 않았습니다. 이전 패치판의 상태 저장은 사용하지 말고 콜드 부팅하세요.
- 기본 이름 변경은 새 게임에서 초기화되는 값입니다. 기존 세이브나 상태 저장 속 이름은 바뀌지 않습니다.
- 원본 BIN/CUE와 메모리 카드 파일은 별도로 백업하세요.

## 권리 및 배포

이 패치는 『봉신연의 애장판』 일본판을 위한 비공식·비영리 팬 번역입니다. 원작, 게임 프로그램, 영상·음악·그래픽·상표의 권리는 KOEI 및 각 권리자에게 있으며, 본 프로젝트는 권리자와 제휴하거나 승인을 받은 것이 아닙니다. 배포물에는 원본 또는 패치된 전체 게임 디스크 이미지와 BIOS가 포함되지 않으며, 번역 적용용 차분 패치, CUE, 적용 도구 및 문서만 포함됩니다. 이용자는 정품 디스크를 소유하고 개인적으로 덤프한 지원 원본을 준비해야 합니다. 패치된 게임 이미지의 업로드·공유·판매 및 ROM 요청은 금지합니다.

동봉된 xdelta3 실행 파일은 Apache License 2.0에 따라 재배포되며, 관련 고지와 라이선스는 `tools` 폴더에 있습니다.
